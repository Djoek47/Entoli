How it works

From repository to a skill your app can use

Six steps, in this order. You can do them yourself with our keys and docs, or let us do them for you over MCP.

  1. Connect your code

    Sign in with GitHub and pick a repository. We read it; we never write to it unless you ask.

  2. Analyze

    AI finds your screens, menus, buttons, settings and the code behind each one, and learns your naming and style.

  3. Map the app

    Every path through the interface: this menu has two buttons, each opens two more, and so on, until the whole app can be navigated.

  4. Teach knowledge

    You say what the app can and can't do, so it never promises a feature it doesn't have.

  5. Train and test

    Try it in the Studio, correct what it gets wrong, and watch coverage climb until every path is reachable.

  6. Ship the skill

    One file, entoli.skill.json, plus the SDK. Your app is now operable by intent, with text or with voice.

Integration depth

Three layers. You choose how deep.

L1Available now

Control

No AI at runtime. The user types or speaks, and the menu responds: Entoli opens menus, fills forms and runs actions on the device, always on a card the user can see and stop.

  • You pick which features it may touch
  • Works from your UI map, no deep code access
  • Like ChoreMaxx: chores, rewards, calendars by voice
L2Available now

Integrated

The user speaks and Entoli's AI answers, then makes the change through your UI, on the same card. It learns your codebase and style. Choose Layer 1, Layer 2 or off for each feature.

  • Reads the code behind every screen
  • Settings and permissions by voice, confirmed
  • Like Circe et Venus: the whole platform, spoken
L3Coming

System

Below the app: Entoli built into the operating system itself, on our own Linux distribution. Every app on the machine, one mind.

  • Kernel-level integration
  • Cross-app intent
  • In development

Text mode

Fewer AI calls · lower cost

Typed intent and taps. Most requests are resolved on the device from your map, without a model.

Voice mode

More AI · higher cost

Spoken intent, speech back, and voice-only control of settings in Layer 2.
